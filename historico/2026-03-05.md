## Decisões técnicas importantes

- **Rate limiting in-memory** em vez de Redis/Upstash — suficiente para o tamanho atual, sem custo extra
- **Auth split** (`auth.config.ts` + `auth.ts`) — padrão recomendado pelo NextAuth v5 para evitar bcryptjs no Edge Runtime
- **Middleware bundle** caiu de 112 kB para 87.1 kB após o split
- **Zod** para validação de todos os endpoints de API
- **Sanitização HTML** nos campos de texto (strip tags + chars de controle)
- **Senha mínima 8 chars + 1 número/símbolo** (mais seguro que os 6 anteriores)

## Security headers implementados

- `Content-Security-Policy` — restringe fontes de scripts, estilos, conexões
- `Strict-Transport-Security` — HSTS 2 anos com preload
- `X-Frame-Options: DENY` — bloqueia clickjacking
- `X-Content-Type-Options: nosniff` — bloqueia MIME sniffing
- `Referrer-Policy: strict-origin-when-cross-origin`
- `Permissions-Policy` — desabilita camera, mic, geoloc, payment
- `X-DNS-Prefetch-Control: off`
