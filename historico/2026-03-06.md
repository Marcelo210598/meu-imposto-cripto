# Snapshot - 06/03/2026

## O que foi feito hoje

- Adicionado suporte a importação de PDF da Binance (Spot - Histórico de Trades)
- Tentativas de solução server-side falharam por deps nativas do Vercel:
  - `pdf-parse` → depende de `@napi-rs/canvas` (não roda em serverless)
  - `pdfjs-dist` server-side → precisava de build legacy + worker, instável no Vercel
- Solução definitiva: **parse client-side no browser** com `pdfjs-dist`
  - Worker copiado para `public/pdf.worker.min.mjs` (CSP-safe, sem CDN)
  - Parser ajustado para o formato real do PDF Binance PT-BR

## Decisões técnicas importantes

- **Client-side é a abordagem correta para PDF** — browser tem todas as APIs nativas
- Rota `/api/parse-pdf` removida (desnecessária após migrar para client-side)
- `serverExternalPackages` removido do `next.config.ts`

## Formato real do PDF Binance (descoberto via teste local)

```
Tempo   Par   Lado   Preço   Executado   Quantidade   Taxa
26-03-02 21:11:06   ETHBRL   SELL   10502.13   0.1705ETH   1790.613165BRL   1.79BRL
```

- Data: 2 dígitos de ano (`26-03-02` → `2026-03-02`)
- Números colados com unidade: `0.1705ETH`, `1790.613165BRL`
- Colunas em português, mas BUY/SELL em inglês

## Problemas encontrados e soluções

- **Problema:** `pdf-parse` → `@napi-rs/canvas` não disponível no Vercel serverless
- **Solução:** migrar para client-side com pdfjs-dist no browser

- **Problema:** regex inicial errado (esperava `2026-03-02`, PDF tem `26-03-02`)
- **Solução:** ler o PDF localmente com node, ver o texto real, corrigir regex
