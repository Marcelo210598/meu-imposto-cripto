## 🎯 O que foi feito hoje (Sprint 3)

### PTAX Automático (Banco Central)
- `src/app/api/ptax/route.ts` — proxy server-side para a API oficial do BCB
  - `GET /api/ptax?data=YYYY-MM-DD` — cotação única
  - `GET /api/ptax?datas=YYYY-MM-DD,YYYY-MM-DD,...` — cotações em bulk (parallel)
  - Cache em memória de 12h para evitar múltiplas chamadas
  - Recua até 7 dias se a data for feriado/fim de semana
  - Endpoint: `CotacaoDolarDia` (sem filtro tipoBoletim — endpoint já retorna fechamento)
- Integrado ao `upload-csv.tsx`:
  - Detecção automática de exchanges internacionais após parse do CSV
  - Painel âmbar de conversão com preview das cotações USDT/USD→BRL
  - Botão "Buscar PTAX e Converter" → fetch bulk por data → lista cotações
  - "Confirmar e importar" aplica a conversão antes de salvar no DB
  - Opção "Importar sem converter" para quem prefere ajustar manualmente

### Relatório IRPF (`/relatorio`)
- `src/lib/relatorio.ts` — funções de geração do relatório:
  - `gerarRelatorioAnual(operacoes, ano)` — relatório completo por ano
  - `gerarCSVOperacoes(operacoes)` — CSV de exportação com BOM UTF-8
  - `gerarTextoGCAP(relatorio)` — texto estruturado para preenchimento no GCAP
  - `extrairAnosComOperacoes(operacoes)` — anos disponíveis para seleção
- `src/app/relatorio/page.tsx` — página autenticada com:
  - Seletor de ano calendário (apenas anos com operações)
  - Cards: Total Vendas, Ganho de Capital, Imposto Devido, Meses Tributáveis
  - **Seção 1**: Bens e Direitos (Grupo 08 - Criptoativos)
    - Código IRPF: 01 (BTC), 02 (ETH), 09 (outros)
    - Situação em 31/12/ano anterior e 31/12/ano declarado
    - Discriminação e custo de aquisição
  - **Seção 2**: Ganho de Capital mês a mês
    - Total vendas, ganho, imposto, status (DARF / Isento / Sem vendas)
    - Totais do ano ao final
  - **Seção 3**: Rendimentos Isentos e Não Tributáveis (se houver)
    - Código 05 IRPF, total de ganhos isentos
  - **Seção 4**: Dados para GCAP (colapsável)
    - Preview do texto formatado para preenchimento manual no GCAP
    - Botão "Copiar dados GCAP" (clipboard)
    - Botão "Exportar CSV completo" (download)
  - Botão Imprimir (CSS print-friendly)
  - Aviso legal

## 📝 Decisões técnicas
- PTAX: endpoint `CotacaoDolarDia` não aceita filtro `tipoBoletim` — removido, o endpoint já retorna o fechamento
- Cache PTAX server-side (Map em memória) — evita múltiplas chamadas ao BCB na mesma sessão
- Conversão PTAX: feita client-side antes de salvar, valores convertidos ficam em BRL no DB
- Exchange field: "Bybit (USDT)" → "Bybit (convertido)" após conversão
- Códigos IRPF: BTC→01, ETH→02, USDT/USDC→03, outros→09
- CSV exportado com BOM (\uFEFF) para compatibilidade com Excel BR
